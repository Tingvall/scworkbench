# Evidence Bundle Checklist

Include all of the following before handing to writer.

- [ ] analysis report markdown (`report.md`)
- [ ] rendered report (`report.html`)
- [ ] replay script (`analysis_script.R`)
- [ ] run context (`run_context.json`)
- [ ] DAG nodes/edges (`dag_nodes.csv`, `dag_edges.csv`)
- [ ] key result tables (DE/pathway/etc)
- [ ] key plots (>= 3 for primary analysis)
- [ ] run ledger snapshot (`run_ledger.csv`)
- [ ] session log (`session_log.md`)
- [ ] claim-to-evidence map (`claim_evidence_map.csv`)
