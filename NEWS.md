# scworkbench 0.1.0

## Operation Pack SDK

- Adds an ABI-v3 `effective_cell_coverage: "reference_only"` declaration for
  required, alignment-none observation tables and required, independently
  authenticated self-linked models. Supporting reference data remains fully
  authenticated while no longer filtering a disjoint query-cell axis.
- Adds an installed ABI-v3 R scaffold, explicit static/trusted check tiers,
  reader-only partition mapping, core-owned contract-test helpers and an
  executable scaffold-to-relocated-recipient tutorial.
- Freezes the public author interface, callback/context inventory, all accepted
  declaration branches and validated declaration recipes. Python support is
  reported per policy rather than inferred from shared schema acceptance.
- Reuses ABI v2's reserved-namespace guard in ABI v3 admission; no protocol,
  identity scheme, official pack or standard-profile change is introduced.

## Bundle substrate

- Introduces portable, disk-backed single-cell bundles with typed matrices,
  spaces, models, sets, vectors, tabular artifacts, and provenance.
- Adds public getters, registered operations, closure-aware promotion, strict
  replay, recipient finalization, and read-only audit.
- Adds durable resumable sessions and capability-scoped PyBench protocol v2
  transitions for long-running Python methods.

## Analysis capabilities

- Adds container ingestion for 10x Matrix Market, Seurat,
  SingleCellExperiment, and AnnData inputs.
- Adds conventional RNA representation, scVI, PeakVI, Palantir, Monocle3,
  Slingshot, metadata diagnostics, differential testing, enrichment, and
  composite trajectory operations.
- Adds factual per-cell RNA QC metrics with separately retained threshold
  recipes, explicit source-derived Slingshot fit adoption without refitting,
  and model-bound union of fitted and projected PeakVI/scVI latent spaces.

## Release engineering

- Extracts six terminal statistical methods into the independently installed,
  explicitly activated ABI v2 `scwbStatistics` pack. Core retains durable state
  ownership, pack-free inspection, and historical unqualified provenance while
  prospective execution records qualified `scwbstatistics::` identities.
- Completes the synthetic operation-pack ABI v2 R/Python reference boundary:
  explicit installed Python-pack authentication, `pybench-op-v3` typed staging,
  independent receipt/runtime/payload audit, atomic durable publication, and
  pack-free recipient reopen. The former `py_protocol_hello` operation is now
  private historical compatibility code rather than a production catalog item.
- Adds complete-discovery CI, source-package policy checks, composite release
  metadata, immutable base-image and runtime locks, source artifact builders,
  release evidence assembly, and explicit GPU/large-data gates.
- Seurat is now optional; core installation no longer pulls it transitively.
- UMAP replay now declares cell-aligned embedding validity separately from raw
  coordinate and serialized-model identity, avoiding false exact-replay claims
  across fresh processes.
- Provenance run, contract, structural, and materialization identities now use
  explicit SHA-256 schemes, eliminating large-payload integer overflow while
  retaining bounded validation of already-persisted legacy identities.
