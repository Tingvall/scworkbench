# Public graph SDK reference

This project requires explicit ABI4 activation. Namespace loading registers no
operations. Declare typed inputs and outputs, request readers, compute and emit
primitives. Core authenticates retained sources, enforces alignment and ceilings,
creates receipts and publishes the complete promotion closure atomically.

The matrix example uses a small materialized input and a partitioned graph
writer. The graph summary consumes all bounded components without collecting
the graph. The annotation example uses the budgeted convenience collector and
an issued retained-cell-axis projection; it has no matrix-source certificate.
It preserves existing attributes and adds one unique `annotation` field;
an existing field with that name rejects rather than silently replacing it.
Do not substitute identifiers, paths or an author-generated hash for authority.

Run `wb_operation_pack_check(path, "contract", trusted = TRUE)` for the installed
public lifecycle and rollback tests. See the installed GRAPH_GUIDE.md for the
large graph and adapter boundaries. No direct SQL or engine-internal API appears
in a runner. This is an authoring reference, not a scientific method.
