# Phase 4A RNA/Representation capability ledger

This ledger is the ordered decision record derived from Sable's survey at
`8799adcc41e41bc7e33f1a42a022e98f102de09e` against scworkbench
`19b69bd99bccd81b4e62d839c7d4016984aeec36`. The CSV is the tabular source and
the JSON is its deterministic machine-readable projection. The checker rejects
missing fields, classifications outside `demonstrated_gap` and
`unproven_runtime_surface`, source-anchor drift, duplicate issues, and any method
set other than the nine deferred RNA/Representation methods.

No ledger row is implemented in this pilot. `leiden` is intentionally absent:
it is the independently packaged provisional pilot and is not evidence that the
remaining Representation surface is complete or standard. Proposed remedies
remain generic: no row authorizes a pack to receive a bundle, database handle,
private getter, or operation-specific engine exception.

Implementation order is RNA-1 through RNA-4, then Representation-1 through
Representation-4. Shared remedies are grouped as authenticated axes and
annotations, staged materialization and dimensions, model payload and merge,
and sparse relational axes. Any remedy that changes the shared protocol must be
returned to Quill for a language-neutral specification before implementation.
