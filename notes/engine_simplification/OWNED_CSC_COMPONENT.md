## Identical bytes, less representation work

Only the literal selected-value helper supplies its already-owned sparse
projection. C admission requires an ordinary Matrix dgCMatrix with known class,
package, attributes and slots; plain non-ALTREP carriers; exact dimensions;
valid pointer lengths/start/order/tail and strictly ordered in-range row indices.
Complete structural preflight occurs before entry emission. Unsupported,
opaque, malformed and empty-axis cases decline to the ORIGINAL callback and
coercion path, rather than sorting, repairing or inventing a new validity error.
Nonordinary widths likewise preserve original sequence evaluation/errors; no
new width inspection occurs on the default callback-only route.

The existing record/number/coordinate formatter reads CSC slots directly instead
of making column subsets, coerced copies and coordinate/index vectors. Same
column-major order, global1-based coordinates, NA/NaN/signed-zero filtering,
64KiB buffer, token cache and SHA/file sink. Every actual emitted value is still
examined; infinity and unsupported exponent errors use the same formatter.
Preflight/column/value iteration checks interrupts, including empty columns and
filtered values. Existing unwind cleanup owns the sink. No original low-level
array-append prefix/error contract changed.

Additional formatter workspace is constant, but the source matrix is already
owned: this is not an unlimited-memory streaming API or a claim that all caller
matrices are128-column blocks. Preflight is O(nnz+ncol) metadata traversal,
not removal of scientific authentication or a new source authority/cache.
Ordinary source callbacks, grants, receipts, source checks and identities stay
unchanged. No protocol/schema, scientific pack, parameter or supported backend
boundary changes.
