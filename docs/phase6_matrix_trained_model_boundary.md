# Phase 6 matrix-trained contained-model boundary

ABI-v3 `matrix_trained_contained_model_closure.v1` is generic. A declared model
terminal names one authenticated matrix input, its exactly-once typed matrix
slice, a paired fitted latent `space` materialization, latent-dimension
parameter, and complete required sibling outputs. Core binds matrix content
and descriptor identities, exact ordered fitted cells and features, source
snapshot, paired space ID/dimensions, model tree, promotion group, and receipt
observation. A G1 model read reauthenticates the retained matrix and fitted
space before exposing private model bytes. The pre-execution linkage fixes
the allocated fitted-space ID; the post-execution receipt binds that ID to
the space's canonical content identity. On G1 reopen, core follows the
promoted artifact-to-run binding to exactly one validated terminal receipt,
then recomputes its paired-space identity from the current durable
coordinates. Missing, ambiguous, or changed evidence rejects, including a
self-updated HDF5 registry checksum. Staging, promotion, and rollback
remain core-owned; packs receive no bundle/SQL/committed path authority.

The shared manifest, request, receipt schemas and identity fixture are in
`inst/protocol/`. They retain canonical JSON v1. Python has schema and
canonical-identity parity but no direct runtime for the new grant; an
unsupported Python execution request rejects before stage mutation.
Existing space-trained G2/G1 identities are unchanged.

`peakvi_fit` and `peakvi_project` are now owned by the explicitly activated
`scwbLatent` CPU operation pack under qualified names. The unqualified
historical core implementations are no longer executable. Existing promoted
PeakVI runs remain inspectable without loading the pack and are not rewritten
or reinterpreted as pack runs. The accepted old-core numerical comparator is
retained in the pack's pinned migration tier.

`model_bound_latent_union` is owned by `scwblatent::model_bound_latent_union`.
Its ABI-v3 contract binds separate complete reference and query axes, a
retained producer transition, the fitted model payload, and a declared ordered
union. Core authenticates these grants and writes the complete space and
summary output closure. Historical core runs remain inspectable without the
pack.

`scvi_train` has subsequently migrated to `scwblatent::scvi_train`. The
generic ABI-v3 ordered cell-metadata snapshot binds batch, categorical and
continuous fields to the fitted matrix axis; an opt-in typed-slice policy
checks count-like values. PeakVI's own fit declaration still forbids a
non-null batch key and its scientific code is unchanged.
